# Read First

Purpose: front door for any LLM or agent using this wiki.

Status: active current spine note.

Use this when:
- you are entering this wiki for the first time
- you need to understand how to use the wiki safely
- you need to know what to read before acting

Current truth:
- This wiki is both a personal harness and a shared long-form working space.
- It is meant to hold more of Josh's durable frame, intentions, plans, and project context than injected agent memory can hold.
- Injected memory should be treated as a small steering/index layer. The wiki is the main long-form surface.
- Simplicity matters. Most notes are just markdown with information in them. Only a small number of notes in `current/` are the living control surface.
- `current/` outranks scattered notes elsewhere for present framing, intentions, and operating rules.
- `current/` is the front door and lowest-entropy routing layer, not a proof that every claim inside it is closed doctrine.
- Treat wiki claims by evidence status where possible: some are stronger/proven, some are still candidate interpretations, and some remain explicitly open.
- The harness should bias readers toward a distinguishability-first and constraint-first frame: differences matter only when the active probes, support layers, and constraints let them resolve, persist, and become load-bearing.
- Do not presume primitive causality. In this system, causal narration is at best a later admissible description, not a front-door starting point.
- The manifold/support layers should be used to clean up default object-first and causality-first reasoning at each level rather than quietly importing those defaults upward.
- `concepts/` is the large knowledge field. `projects/` holds project-specific context. `raw/` is intake/source material. `archive/` is older settled material.

- treat legacy material as current unless `current-vs-legacy.md` or a current note says so
- rewrite the user's stable preferences casually
- assume all notes are equally current, safe to edit, or load-bearing
