## 3. The governing Ratchet principle

At comparison tick \(t\), freeze the complete context

\[
K_t=(D_t,G_t,\Pi_t,\{\preceq_{t,j}\}_j,C_t,H_t),
\]

where \(D_t\) is the finite demand/observation record, \(G_t\) is a replaceable candidate grammar and nesting-diagram population, \(\Pi_t\) is the common executable probe family, \(\preceq_{t,j}\) are explicit plural presumption/weakness orders, \(C_t\) contains hard controls and claim ceilings, and \(H_t\) is retained comparison history.

The Ratchet compares candidates; it does not prove an absolute MSS:

\[
P_t=G_t(D_t,H_t),\qquad
M_t(p)=\Pi_t(p;D_t),
\]

\[
A_t=\{p\in P_t:C_t(p,M_t(p))\},
\]

\[
F_{t,j}=\operatorname{Min}_{\preceq_{t,j}}(A_t),
\qquad
F_t=\{F_{t,j}\}_j.
\]

Incomparable candidates stay alive. A runnable default is always retained. The permanent object is the receipt/history of what was compared under which frozen context—not the current winner.

For a nested manifold candidate, local edits never win independently. A proposal is first resettled as a complete coupled object:

\[
\widehat Z\in
\operatorname{Settle}_{G'}
\bigl(\operatorname{Propose}(Z,y)\bigr).
\]

If different finite settlement orders reach different fixed points or cycles, every resulting settled whole state is a separate candidate. The next frontier is

\[
\mathcal F_{t+1}
=
\operatorname{ND}_{\preceq_{D_t}}
\left(
\mathcal F_t\cup\{Z_{\mathrm{default}}\}\cup
\{\widehat Z_1,\ldots,\widehat Z_m\}
\right).
\]

No unrelated entropy quantities are silently summed to choose a winner.

## 4. Correct whole-state mathematical object

Let \(I_G\) be the finite category/poset of active contexts, cuts, shells, and attachment relations in nesting diagram \(G\). For each \(A\in I_G\), let \(X_A^t\) be the finite searched candidate/survivor set at the current Ratchet tick, and let \(\Pi_A\) be its licensed probe family.

The operational quotient is

\[
Q_A^t=X_A^t/{\sim_{\Pi_A}},
\qquad
x\sim_{\Pi_A}x'
\iff
\pi(x)=\pi(x')\quad\forall\pi\in\Pi_A.
\]

Every restriction/coarse-graining map \(C_{AB}:X_A^t\to X_B^t\) for \(B\subseteq A\) must respect the quotient:

\[
x\sim_{Π_A}x'
\Longrightarrow
C_{AB}x\sim_{Π_B}C_{AB}x'.
\]

Only then is

\[
\bar C_{AB}:Q_A^t\to Q_B^t
\]

well defined. The global compatible-section set is

\[
\Gamma_t(Q;G)
=
\left\{
(q_A)_{A\in I_G}:
\bar C_{AB}(q_A)=q_B
\ \forall(B\subseteq A)
\right\}.
\]

The finite extension fibre is

\[
\mathcal F^{X,t}_{A/B}(q_B)
=
\{q_A\in Q_A^t:\bar C_{AB}(q_A)=q_B\},
\]

and its licensed finite capacity is

\[
\kappa^{X,t}_{A/B}(q_B)
=
\log_2\left|\mathcal F^{X,t}_{A/B}(q_B)\right|.
\]

For a continuous density-matrix fibre, \(\log|\mathcal F|\) is invalid because the fibre is generally uncountable. If smooth interpolation is needed, use a declared metric \(d\), resolution \(\epsilon\), and covering number

\[
\kappa_{\epsilon}(\mathcal F;d)=\log N_{\epsilon}(\mathcal F,d).
\]

A complete candidate can therefore be represented as

\[

\left(
G,
\Omega,
\{X_A^t,Q_A^t,\bar C_{AB},\mathcal F^{X,t}_{A/B}\},
\Gamma_t,
\{\Phi_{e,k}\},
\{\mathcal I^y_{e,k}\},
\Pi,

\mathcal H,
\mathcal P,
\mathcal R
\right),
\]

where \(\Omega\) is the global state, \(\Phi_{e,k}\) are engine-stage channels, \(\mathcal I^y_{e,k}\) are outcome-conditioned instruments, \(\mathcal H\) is retained coherent/ordered history, \(\mathcal P\) is Purgatory, and \(\mathcal R\) is the immutable receipt ledger.

Pairwise marginal agreement is not sufficient to establish a global quantum state. Whole settlement must solve the quantum-marginal feasibility problem

\[

\quad
\operatorname{Tr}_{\bar A}\Omega=\rho_A

For nontrivial marginals this is an SDP feasibility problem, not a string equality test.
