## 4. Whole entropic-geometric feedback

The later geometry requirement re-opened every earlier candidate.  The engine
simulated 528 complete base/nesting/geometry combinations.  The current whole
frontier contains six:

- classical distribution + complete pairwise + Shannon–Fisher;
- classical distribution + ternary relation + Shannon–Fisher;
- finite automaton + complete pairwise + Shannon–Fisher;
- finite automaton + ternary relation + Shannon–Fisher;
- finite relation + complete pairwise + Shannon–Fisher;
- finite relation + ternary relation + Shannon–Fisher.

The classical distribution re-entered from Purgatory because it already has a
real scalar probability carrier.  The relation and automaton require an
auxiliary scalar lift but make fewer assumptions elsewhere.  These tradeoffs
are incomparable under the declared vector.

For all six candidates:

- baseline and expanded source relations are exact: 7 then 8 complete states;
- entropy-potential chain error is `0.0`;
- Fisher-metric chain error is `0.0`;

- expansion changes the pairwise inner operator by `0.02859992266325906`;
- expansion changes the ternary inner operator by `0.015439526794179537`.

The different pairwise and ternary operator digests show that equal admissible
history sets do not make the two nesting presentations functionally identical.
