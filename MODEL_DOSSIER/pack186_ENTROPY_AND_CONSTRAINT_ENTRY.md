## Shannon entropy is not the manifold foundation

The repository source says the primitive is constrained distinguishability,
not generic entropy, and that entropy is a later licensed measure.  Pack 184's
universal Shannon/Fisher construction therefore did not follow the owner
constraints.

This run uses different entropy objects only where their mathematical carrier
exists:

| Entry point | Constraint now available | Licensed readout |
|---|---|---|
| Root comparison | Finite continuation classes and retained records | `log2` finite class/continuation count; no probability law assumed |
| Density carrier | Positive trace-one operator | von Neumann entropy `S(rho)` |
| Declared cut | Partial trace and complementary subsystem | cut entropy, mutual information, coherent information when its operands exist |
| Relative state/fixed structure | Two positive density operators with compatible support | Umegaki relative entropy `D(rho||sigma)` |
| Entropic geometry | A smooth family of licensed cut densities | BKM metric as the Hessian of Umegaki divergence |
| Terrain flow | A CPTP/GKSL flow and its fixed structure | entropy change and relative-entropy contraction, typed per terrain |
| Classical record | An explicit computational-basis measurement/cut | Shannon entropy of the classical outcome probabilities only |

The live native terrain census reinforces this distinction.  Raw von Neumann
entropy is not monotone on every terrain: amplitude damping can increase and
decrease it.  Relative entropy to the appropriate fixed structure is the
reliable pawl in those lanes.  So neither raw `S` nor Shannon entropy can serve
as a universal Ratchet score.

## Constraint entry order in the executed object

1. Finitude bounds histories, parameters, and carrier dimension.
2. Operational distinguishability fixes what counts as the same density-level
   state while allowing fiber memory above it.
3. N01 keeps update order and complete histories.
4. Positivity/normalization and partial-trace compatibility license density and
   marginal strata.
5. Complex projective spinors license Hopf phase and Weyl orientation.
6. Entanglement modifies naive product tori into marginal-radius shells and
   Schmidt strata.
7. Declared cuts license Umegaki divergence; its Hessian supplies the induced
   BKM geometry.
8. Distinct shells plus phase connection license cross-shell Berry flux.
9. Weyl sheets constrain four terrain flows each.
10. Terrain flow plus noncommuting operator order licenses sixteen stages.
11. Downstream terrain/stage viability returns outward, changes the carrier,
    and forces all affected geometry and entropy to be recomputed.
12. A 7D octonion readout or 27D Albert carrier may be attached only when a
    measured residual needs it.

Axis 0 has two roles without contradiction.  Its drive is present at the root
as the gap between finite possibility capacity and retained record capacity.
Its late readout is an unfused list of typed measurements—possibility change,
boundary entropy, binding information, coherent-path evidence, and ordered
stage gap.  The code does not collapse these into a made-up master scalar.
