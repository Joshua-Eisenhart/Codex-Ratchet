The proposed engines do not follow from finitude, nesting, maximum support entropy, a nontrivial
symmetry group, noncommutation, or toroidal topology alone. Those structures can supply possible
degrees of freedom. An engine is admitted only when the dynamics additionally supplies:

\[
\boxed{
\text{recurrent channel}
+\text{nonzero generalized force}
+\text{stationary current}
+\text{load/output}
+\text{conservation law}
}
\]

For a finite transition network with incidence matrix \(B_k\), edge rates \(w_{ij}^{(k)}\), and
cycle \(c\), the operational conditions are

\[
\beta_1(G_k)=\dim\ker B_k>0,
\]

\[
\mathcal A_c
=
\sum_{(i\to j)\in c}
\log\frac{w_{ij}^{(k)}}{w_{ji}^{(k)}}
\ne 0,
\]

\[
B_kJ_k=0,\qquad J_c\ne0,
\]

\[
P_{\mathrm{out}}=J_c\,\mathcal A_{\mathrm{load}}>0,
\]

\[
P_{\mathrm{in}}-P_{\mathrm{out}}=\sigma\ge0
\]

in dimensionless units. The last two lines distinguish an engine from an oscillator or a
circulating current.

The computational finding is a **constraint window**, not “the tightest possible constraint”:

| Constraint depth | Cycle-space dimension |
|---:|---:|
| 0 | 3 |
| 1 | 2 |
| 2 | 1 |
| 3 | 0 |
| 4 | 0 |

Constraint can isolate one cycle from a larger cycle space. Further constraint can destroy it.
The engine-supporting layer is therefore a critical or residual layer at which one or more
load-bearing recurrent modes survive—not necessarily the deepest layer.

## 2. Finite base and ordered deformations

Let a finite numerical frame be

\[
\mathfrak F_n=(X_n,o_n,\delta_n,\iota_n),\qquad |X_n|=2^n,
\]

where \(o_n\) is a declared origin, \(\delta_n\) a resolution, and \(\iota_n\) a representation
map. Its maximum support entropy is

\[
S_0(\mathfrak F_n)=\log_2|X_n|=n.
\]

Growth is not a hidden passage to an infinite completion. It is a declared map

\[
g_{n,m}:\mathfrak F_n\longrightarrow\mathfrak F_m,\qquad m>n,
\]

which must preserve or explicitly transform origin, resolution, and already represented values.

Given probes \(\mathcal M_k\), define finite indistinguishability by

\[
x\sim_{\mathcal M_k}y
\iff
m(x)=m(y)\quad\forall m\in\mathcal M_k.
\]

Given constraints \(C_1,\dots,C_k\),

\[
A_k=\{x\in X_n:C_1(x)\land\cdots\land C_k(x)\},
\qquad
Q_k=A_k/{\sim_{\mathcal M_k}}.
\]

The nested manifold candidate is an ordered deformation tower:

\[
\mathfrak M_k
=
D_k\circ D_{k-1}\circ\cdots\circ D_1(\mathfrak F_n).
\]

Each \(D_k\) may install a partition, weighting, linear carrier, tensor factorization, grading,
connection, generator, record, or bracket law. A proposed layer is earned only if:

1. its domain and codomain are declared;
2. it preserves the required lower-layer constraints;
3. it creates an invariant or comparison not defined before it;
4. deleting it removes or changes that invariant;
5. no admitted relabeling, gauge map, or reparameterization reproduces the change;
6. its projection to lower layers is compatible with the rest of the tower.

Order is content when

\[
[D_i,D_j]
=
D_i\circ D_j-D_j\circ D_i\ne0.
\]

Nonassociativity is a separate, stronger question:

\[
\operatorname{Assoc}(D_i,D_j,D_k)
=
(D_i\circ D_j)\circ D_k
-D_i\circ(D_j\circ D_k).
\]

Noncommutation does not imply a nonzero associator. Neither condition, alone, implies an engine.

## 3. Dynamic compatibility of the quotient

An indistinguishability quotient must respect the dynamics. For a deterministic map \(f:X\to X\),

\[
x\sim y\Longrightarrow f(x)\sim f(y).
\]

For a Markov generator \(W\), strong lumpability requires

\[
\sum_{z\in B'}W_{xz}
=
\sum_{z\in B'}W_{yz}
\quad
\text{for every pair }x,y\in B
\text{ and every block }B'.
\]

Otherwise a quotient can manufacture an apparent loop that is not a well-defined quotient
dynamics.

The executable test used the acyclic path

\[
0\to1\to2\to3\to3
\]

and identified \(0\sim3\). The displayed quotient appears to contain

\[
[0]\to[1]\to[2]\to[0],
\]

but the partition fails dynamic compatibility because \(f(0)\not\sim f(3)\).

The exhaustive four-state test checked:

| Quantity | Result |
|---|---:|
| Deterministic maps with no nontrivial cycle | 125 |
| Dynamics-compatible quotients checked | 939 |
| Compatible quotients that created a nontrivial cycle | **0** |

This does not prove the statement in arbitrary categories. It does establish the finite
deterministic boundary relevant to the proposed base:

> Distinguishability constraints may expose or merge recurrent structure, but a valid quotient
> of an acyclic deterministic system did not create recurrence. A fake cycle appears when the
> quotient is not compatible with the dynamics.

Therefore engine emergence needs either pre-existing recurrent dynamics, a deformation that
changes the dynamics, internal feedback, or a bifurcation—not only a quotient.

## 4. Six possible emergence routes

### 4.1 Bifurcation of an autonomous vector field

The supercritical Hopf normal form is

\[
\dot z=(\mu+i\omega)z-|z|^2z.
\]

For \(\mu<0\), the origin is attracting. For \(\mu>0\), the stable limit-cycle radius is

\[
|z|=\sqrt{\mu}.
\]

The run recovered:

| \(\mu\) | Measured terminal radius | Prediction | Result |
|---:|---:|---:|---|
| \(-0.35\) | \(7.35\times10^{-23}\) | \(0\) | fixed point |
| \(-0.05\) | \(9.83\times10^{-5}\) | \(0\) | decaying |
| \(0.10\) | \(0.3162277660\) | \(0.3162277660\) | cycle |
| \(0.40\) | \(0.6324555320\) | \(0.6324555320\) | cycle |

This supplies a precise candidate for “constraint plus drive creates a cycle”:

\[
\mu=\text{destabilizing drive}-\text{transverse contraction}.
\]

It also supplies the negative: increasing contraction through \(\mu=0\) destroys the engine-like
orbit. A limit cycle is an oscillator until a resource and output channel are added.

### 4.2 An internal hybrid controller

The finite controller

\[
\dot x=qv,\qquad q\in\{-1,+1\},
\]

with \(q\) switching sign at \(x=\pm1\), has period

\[
T=\frac4v.
\]

With \(v=0.8\), the measured period was \(5.001\) against \(5.000\). No external stage scheduler
was used. This is the minimal formal answer to the “what advances the stages?” problem:
the phase/controller must be part of the state.

### 4.3 Nonequilibrium current on a finite cycle

For a four-state Markov ring,

\[
k_+=e^{-b+a/2},\qquad k_-=e^{-b-a/2}.
\]

The cycle affinity is \(4a\). The stationary current and entropy production were:

| \(a\) | Current on every edge | Entropy production |
|---:|---:|---:|
| \(0\) | numerical \(0\) | \(2.0\times10^{-31}\) |
| \(0.15\) | \(0.0113054\) | \(0.0067832\) |
| \(0.70\) | \(0.0537917\) | \(0.150617\) |

The current had zero divergence and lay entirely in the ring's one-dimensional cycle space.
This is a steady engine-like cycle even though the probability distribution itself is
stationary. It shows that an engine loop may live in **path current space**, not in a visible
orbit of \(\rho(t)\) or \(p(t)\).

### 4.4 Autonomous conversion against a load

A three-state ring was assigned edge affinities

\[
(\mathcal A_{\mathrm{in}},-\mathcal A_{\mathrm{load}},0).
\]

With \(\mathcal A_{\mathrm{in}}=2\) and load \(0.8\):

\[
J=0.0400643,\quad
P_{\mathrm{in}}=0.0801286,\quad
P_{\mathrm{out}}=0.0320514,\quad
\sigma=0.0480772,
\]

and

\[
P_{\mathrm{in}}-P_{\mathrm{out}}=\sigma.
\]

At load \(2\), the current stalled. At load \(2.6\), it reversed. This is the first test in the
lab admitted as a minimal engine rather than only an oscillator or current.

Rotating the chosen first edge left the cycle affinity \(1.2\) unchanged:

\[
\mathcal A(c)=\mathcal A(\operatorname{rotate}_k c).
\]

Reversing orientation changed its sign:

\[
\mathcal A(c^{-1})=-\mathcal A(c).
\]

This is the exact loop rule: the cycle has no intrinsic first stage; orientation matters.

### 4.5 Stochastic geometric pumping

For Arrhenius rates

\[
k_{i\to j}(t)=\exp(E_i(t)-B_{ij}(t)),
\]

varying only the well depths while keeping the barriers fixed produced integrated currents

\[
(-4.8,1.4,3.5)\times10^{-15},
\]

consistent with zero. Varying wells and barriers out of phase produced

\[
(-0.131075,-0.131075,-0.131075).
\]

This is a concrete form of ordered-deformation pumping: multiple control parameters tracing a
closed loop can generate a geometric current when one-parameter variation cannot. It is
externally driven unless the phase controller is internalized.

### 4.6 Autonomous quantum transport

Two exchange-coupled qubits were evolved with the time-independent generator

\[
\mathcal L(\rho)
=
-i[H,\rho]
+\mathcal D_L(\rho)
+\mathcal D_R(\rho),
\]

\[
H
=
\omega(n_L+n_R)
+g(\sigma_+^L\sigma_-^R+\sigma_-^L\sigma_+^R).
\]

Equal bath excitation targets \(p_L=p_R=0.5\) gave zero excitation current. Unequal targets
\((0.82,0.18)\) gave

\[
J_L=0.1174114,\qquad J_R=-0.1174114,
\]

with current conservation error \(1.7\times10^{-16}\), steady-state residual
\(3.6\times10^{-16}\), and minimum density eigenvalue \(0.0834\).

This is autonomous quantum transport, not yet a quantum heat engine, because the test has no
work repository. It establishes the smallest local mechanism the proposed two-carrier system
would need before adding a battery or load.

| Candidate cause | Necessary? | Sufficient? | Executable result |
|---|---:|---:|---|

| Maximum support entropy | no | no | counts available states; supplies no transition law |
| Nested constraints | no | no | can isolate a cycle, then destroy it |
| Nontrivial residual symmetry | no | no | symmetry does not define transition or current |
| Noncommuting generators | no | no | commutator norm \(2.449\) on a tree, stationary current \(0\) |
| Nonzero cycle space | yes for finite path-current engines | no | equilibrium ring has a cycle but zero current |
| Broken detailed balance / affinity | needed for autonomous steady current | not enough for useful work | biased ring current exists without load |
| Stable recurrence | needed for staged orbit engine | no | Hopf oscillator has no output |

| Load and positive output | yes for an engine claim | nearly, with conservation/stability | three-state converter passed stall and overload controls |

The noncommutation test is especially important:

- Two symmetric edge generators on a three-state tree have
  \(\|[Q_{01},Q_{12}]\|_F=2.449\), yet their sum has zero stationary current.
- One biased ring generator has current \(0.04586\) without requiring a pair of noncommuting
  scheduled generators.

So noncommutation may create order sensitivity or geometric pumping, but it is neither necessary
nor sufficient for autonomous circulation.

### Candidate sixteen-sector factorization

A mathematically clean candidate—not an earned derivation—is

\[
\mathcal S
=
\mathcal G\times\mathbb Z_2^{(\chi)}\times\mathbb Z_2^{(\epsilon)},
\qquad |\mathcal G|=4,
\]

so \(|\mathcal S|=16\), with four generator classes:

| \(g\in\mathcal G\) | Formal generator class | Geometric action |
|---|---|---|
| \(U\) | Hamiltonian derivation \(\mathcal L_U=-i[H,\cdot]\) | isospectral orbit |
| \(M\) | primitive unital GKSL semigroup | mixing toward a full-rank fixed point |
| \(R\) | nonunital GKSL semigroup | relaxation toward a biased fixed point |
| \(P\) | conditional expectation / pinching semigroup | contraction onto invariant strata |

\(\chi\) is a discrete bundle-orientation sector. \(\epsilon\) is a candidate signed placement
sector:

\[
\Psi_{g,\chi,+}
=
e^{\tau\mathcal L_{g,\chi}}\circ e^{+\theta\mathcal K},
\]

\[
\Psi_{g,\chi,-}
=
e^{-\theta\mathcal K}\circ e^{\tau\mathcal L_{g,\chi}}.
\]

This formula is legal when \(\mathcal K=-i[G,\cdot]\) is Hamiltonian. A negative dissipative rate
is generally not completely positive. Therefore any rule saying that a binary axis “changes the
sign of an operator” must distinguish:

- reversible generator sign \(H\mapsto-H\), which is valid;
- orientation or conjugate-channel changes, which may be valid;
- dissipative rate \(\gamma\mapsto-\gamma\), which generally fails physicality.

The 16-sector product becomes an engine only after an autonomous transition law selects and
connects sectors into one or more recurrent cycles.

## 7. Four-stroke analogues without making them literal

Any closed orbit \(\Gamma\simeq S^1\) can be partitioned into four arcs
\(I_1,I_2,I_3,I_4\). The corresponding maps are

\[
\Phi_a
=
\mathcal T\exp\left(\int_{I_a}\mathcal L(\theta)\,d\theta\right).
\]

The cycle map is a cyclic word:

\[
\Phi_{\mathrm{cyc}}=\Phi_4\Phi_3\Phi_2\Phi_1.
\]

Changing the designated first stroke rotates the word. It changes the sampled transient when
the same initial state is held fixed, but does not create a metaphysical first point on the
closed orbit. Reversal changes orientation, affinity, and holonomy.

| Analogue | What transfers | What does not transfer automatically |
|---|---|---|
| Otto | alternation of reversible and dissipative maps; finite stroke word | literal isochoric/adiabatic thermodynamics |
| Szilard | information acquisition, feedback, memory erasure, finite record | free oracle or costless demon |
| Carnot | closed cycle between two generalized potentials; efficiency bound form | literal temperature before Gibbs structure is installed |

For a scientific procedure one may declare a preferred observation phase. That is a convention
on a cyclic process, not an intrinsic first engine stage.

## 8. Geometry–entropy dynamics that may generate the four flow classes

### 8.1 Metriplectic / GENERIC dynamics

A strong candidate backbone not present in the earlier list is

\[
\dot x
=
L(x)\nabla E(x)+M(x)\nabla S(x),
\]

where

\[
L^\mathsf T=-L,\qquad M^\mathsf T=M\succeq0,
\qquad L\nabla S=0,\qquad M\nabla E=0.
\]

The antisymmetric tensor \(L\) generates reversible circulation. The positive tensor \(M\)
generates entropy-producing relaxation. Constraints deform the ranks, kernels, and invariant
leaves of both tensors. This supplies a disciplined route from one coupled geometry–entropy
object to conservative and dissipative engine degrees of freedom.

It does not by itself supply a load or a nonequilibrium force.

### 8.2 Port-Hamiltonian dynamics

For explicit inputs and outputs,

\[
\dot x=[J(x)-R(x)]\nabla H(x)+G(x)u,
\qquad
y=G(x)^\mathsf T\nabla H(x),
\]

with \(J^\mathsf T=-J\) and \(R\succeq0\). This makes power flow and load coupling explicit and is
better suited than an entropy-only story for deciding whether a cycle does useful work.

### 8.3 Basin reduction

For noisy nested basins, Freidlin–Wentzell theory and transition-path theory give

\[
\Pr[x(\cdot)]\asymp e^{-I[x]/\varepsilon},
\qquad
k_{i\to j}\asymp e^{-\Delta V_{ij}/\varepsilon}.
\]

The continuous manifold can then be reduced to a metastable network. Engine emergence is tested
on this reduced network by cycle affinities and currents. The reduction must be checked against
the unreduced dynamics; otherwise an authored basin partition can create the answer.

### 8.4 Hodge and Conley structure

For a cell complex,

\[
C^1
=
\operatorname{im}d_0
\oplus
\operatorname{im}\delta_2
\oplus
\mathcal H^1.
\]

Gradient flow lies in \(\operatorname{im}d_0\), local face circulation in
\(\operatorname{im}\delta_2\), and globally noncontractible circulation in \(\mathcal H^1\).
An engine current need not be harmonic: a contractible local chemical cycle can still operate.
Harmonic current is the stronger condition for topologically protected global circulation.

Conley index and Morse decompositions locate recurrent invariant sets without assuming they are
fixed points. They are appropriate for testing whether the proposed manifold actually generates
cycles, heteroclinic networks, or only a single contraction basin.

The “engine emerges from the deepest ratchet” hypothesis survives only if:

- a recurrent class appears without an authored stage schedule;

## 3. Noncommutation, curl, and detailed balance

For stage maps \(\Phi_i,\Phi_j\), the order defect is

\[
\Delta_{ij}
=
\|\Phi_i\Phi_j-\Phi_j\Phi_i\|.
\]

This establishes order sensitivity. It is not a curl until a state-space
connection, discrete exterior derivative, or probability-current map is
defined.

For a finite Markov process with stationary distribution \(\pi\), the current
is

\[
J_{xy}
=
\pi_xP_{xy}-\pi_yP_{yx}.
\]

Detailed balance is \(J_{xy}=0\) for every pair. Cycle affinity is

\[
\mathcal A_\gamma
=
\log\prod_{(x,y)\in\gamma}
\frac{P_{xy}}{P_{yx}}.
\]

Claude’s T7 correctly demonstrates that a biased three-state Markov cycle has
nonzero affinity and stationary current. It does not demonstrate that a
deformation commutator caused that current.

Executed counterexamples:

- noncommuting quantum stages with a shared invariant axis: order gap \(0.105\),
  current-area \(0\);
- a single Markov generator, with no pair of scheduled deformation maps,
  carries stationary current \(1/3\).

Therefore noncommutation is neither sufficient nor necessary in general. It
can be a model-specific source of current only after a controlled ablation
shows:

\[
\Delta_{ij}\to0
\quad\Longrightarrow\quad
J\to0
\]

while the carrier, drive, stationary distribution, and other couplings are
held fixed.

## 4. Hodge decomposition: what it earns

The attached calculations correctly recover:

- a sphere has no nonzero harmonic one-form;

There is an additional nesting boundary:

Each fixed-\(\eta\) Hopf torus has two leafwise cycles, but the full Hopf

not automatically a global harmonic current. The model must test:

1. whether the dynamics remains confined to \(T_\eta\);
2. how currents transport when \(\eta\) changes;
3. whether leafwise classes survive the enclosing geometry;
4. whether the measured phase is curvature holonomy, harmonic current, or
