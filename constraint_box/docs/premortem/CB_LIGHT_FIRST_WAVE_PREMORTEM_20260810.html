Planning/falsification artifact only. It is not a wave run, tool admission, portability proof, real model/skill invocation, or promotion evidence.

Premise

Six months later, the first CB Light fixture wave failed: its receipts and graphs looked convincing, but it could not prove what ran, whether inputs were independent, or whether model-shaped output affected deterministic settlement.

Fixture under test

  1. Seal a typed IssueCard and strict ProbePacket.
  2. Run exactly three local deterministic fake adapters: witness, falsifier, evidence map.
  3. Check topology with Rustworkx; settle a locally recomputed FactSet with Z3 plus enumeration.
  4. Write append-only SQLite attempt/receipt lineage and replay from raw observations.
  5. Return SETTLED, HOLD, REFUSE, or EXPIRED; always promotion_allowed=false.

Agent grid — independent failure modes

Authority / provenance

Typed reference was rendered as “asset used,” without an invocation receipt.

Safeguard: state machine declared → resolved → bound → invoked → receipt_verified; only the last may be cited.

Input diversity

Plural councils shared one packet, evidence digest, adapter, prompt, and seed.

Safeguard: record context/evidence/lineage/adapter/seed hashes and deny corroboration credit to correlated branches.

State / lineage

Retries overwrote or joined a different attempt’s receipts.

Safeguard: distinct plan fingerprint and immutable attempt ID; content-addressed raw receipts; HOLD on incomplete closure.

Gate non-authority

Adapter PASS or model verdict became a solver input.

Safeguard: gate only a whitelisted, freshly reverified FactSet; adapters emit observations, never verdict/promotion.

Scope creep

Generic orchestration and simulation placeholders hid the finite fixture’s boundary.

Safeguard: frozen allowlist: stdlib SQLite, Pydantic/jsonschema, Rustworkx, Z3/enumerator, three fake adapters.

Receipt tamper / missing falsifier

HOLD; no stale output may be reused.

Bound but uninvoked asset

HOLD_UNINVOKED_ASSET; reports never say “used.”

Clone / correlation

Visible correlation; no independent corroboration credit.

Replay / duplicate attempts

New immutable attempt, re-execution, verified hashes; no joins or overwrites.

Decision and order

Proceed only with the narrow contained fixture in light_runtime/src/constraintbox. First write schema, FactSet, state machine, and negative controls; then implement and exercise it. Do not add generic nested-council orchestration, PydanticAI, external model execution, or simulation integration to this slice.
