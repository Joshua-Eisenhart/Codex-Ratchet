# Failure memory

These failures must not be rediscovered as attractive proposals without new
evidence.

- **Generic noncommutation:** the reported exhaustive four-state control found
  about 95.7% of arbitrary map pairs noncommuting. `L != R` alone is cheap and
  does not earn the odd gradient, chirality, or ratcheting.
- **Integrated soup:** combining JAX, QIT, Hopfield, spinors, SMT, graphs, and
  entropy in one operation collapses probes, maps, gates, and consumers.
- **Temporary authority:** `/tmp` loss erased campaign rows and wave state.
  Repo-held source, replay receipts, and append-only checkpoints are required.
- **Score-flag Goodharting:** mutable self-loop flags raised a score without
  changing the object. Guard tests and alignment obligations are now fixed.
- **Receipt-shaped control:** schema-shaped or model-reported artifacts do not
  prove provider calls, subagents, MMM reading, source currentness, or a real
  consumer.
- **Environment conflation:** resolving a venv executable to Homebrew Python
  does not erase its environment prefix. Conversely, an editable install can
  silently import a different checkout.
- **Review snapshot called runnable:** a ZIP with documents and hashes is not a
  runnable system until fresh extraction executes its declared verbs and
  verifies its return artifacts.
- **Canonical core freeze:** tool membership is earned by current operation,
  consumer, negative, replay, and boundary evidence—not by a permanent list.
- **Model-policy canonization:** current provider preferences are run data, not
  kernel law.
