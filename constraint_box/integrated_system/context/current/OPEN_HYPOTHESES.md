# Open hypotheses — proposals, not authority

## Structured two-hand field

The working candidate is one finite field with one entropy/time gradient and
two ordered readings. Topology, mass/entropy, and distinguishability should be
derived from the same bound observation table. The structured map-family test
must distinguish this from generic endomap noncommutation.

## Spinor connection memory

A finite quaternion/spinor memory may make stored distinctions form the
connection geometry rather than storing vectors in a pre-existing metric.
Before any operation it needs an explicit finite codebook, signature,
representation, conjugation, product order, and transformation rule. Required
controls include fixed geometry, commuting subalgebra, erased bond geometry,
both hands, and scalar/KNN baselines.

## Hopfield and dense associative memory

Hopfield/Krotov energy is a typed Lyapunov on a declared fibre, not the time
gradient or Hartley support capacity. Useful probes distinguish single-pattern
recall, subset-average false recall, global-average collapse, and one-hand
failure. RSB is a possible later Heavy failure analysis, not a Light layer.

## QIT and bond geometry

Dynamiqs or QuTiP may run small channel/density lifts. Quimb/Cotengra may carry
named bond geometry. Each requires a prior consumer and independent controls.
No package gets to define the ontology.
