# Owner object — current bounded projection

ConstraintBox is deterministic Python code and tools imposing a constraint,
gate, probe, receipt, and retry harness around many short-lived LLMs. Models
propose; deterministic code decides. A model's prose is never its own proof.

## Composition

- **Hooks** remove direct execution authority and relay requests. Hooks are not
  CB and do not make semantic decisions.
- **CB Light** owns finite packets, schemas, constraints, dual solving, bound
  observations, quotients, gates, lifecycle state, and receipt verification.
- **ZIP Agent** is the stateless communication protocol. Tasks, parentage,
  mini-MMM bytes, skills, required outputs, retries, and child ZIPs are explicit.
- **JAX capability runtime** executes declared bounded numerical probes in a
  separate interpreter. It returns observations; it cannot promote itself.
- **Waves** are independently callable skills composed from smaller skills,
  deterministic tools, mini-MMM salience, and bounded loops. Missing receipts
  mean the wave did not run.
- **Human oracle interface** presents compact evidence-backed forms, exposes
  failures and unknowns, and helps construct the next prompt.

## One system, two interpreters

Light, JAX, ZIP Agent, hooks, and waves are one ConstraintBox system. They are
not one Python environment or one mixed operation.

- Light interpreter must not import JAX.
- JAX interpreter is a separately declared capability route.
- Crossing occurs through a typed request and bound observation receipt.

## Mathematical orientation

Identity remains probe-relative: `a = a` iff `a ~_M b` under the declared
finite probe family. Entropy, topology, geometry, and time are investigated as
coupled readings of the same finite leftover, without turning that hypothesis
into package or physics authority.

There is one entropy/time gradient with two ordered hands. `open` and `bind`
must be structured by support extension and probe/constraint restriction. A
generic noncommuting pair is not chirality, ratcheting, or an earned manifold.

## Non-negotiable boundaries

- No provider/model roster in the deterministic kernel.
- No `system_v5` as current CB authority.
- No JAX installation into the Light environment.
- No solver-invented probes treated as observations.
- No graph component called an attractor without a declared update rule.
- No Hopfield energy or memory count written into Hartley support capacity.
- No model, wave, campaign, or receipt promotes itself.
- No Archive path is a live dependency.
