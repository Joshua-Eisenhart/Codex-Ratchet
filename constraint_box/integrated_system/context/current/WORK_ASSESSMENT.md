# Assessment of the work so far

## Useful and retained

- **CB Light:** the contained install, eight declared tool contracts, SMT
  checks, state/receipt machinery, and JAX-negative boundary are real local
  operations.
- **ZIP Agent:** this remains the communication protocol. Its deterministic
  packet/return/replay core has a broad test suite and is part of the product,
  not replaced by a service, chat convention, or single hook.
- **Generic JAX/QIT runtime:** the clean profile has a 112-package lock and 12
  passing API operations covering JAX, QuTiP/JAX, Dynamiqs, Quimb, Stim,
  NetKet, Diffrax, JAXLie/e3nn, Optax/NumPyro, topology tools, SMT/SymPy, and
  Clifford algebra. It is separate from Light and from any old project.
- **Finite manifold capability run:** 6,144 candidates, 972 selected rows, two
  finite recall regions, and QIT checks were reproducible. This is useful
  capability evidence, not a full manifold or admitted basin.
- **Structured open/bind probe:** it distinguishes the named structured family
  from arbitrary maps and retains relabel, missing-row, commuting, and solver
  controls.
- **Public wave runner:** maintenance, context-strategy, and exploration are
  now hash-pinned, contained, executable waves. Composite failure/repair/
  strategy names remain inactive rather than being narrated as runs.
- **Prompt/context custody:** the compact corpus is derived from a verified
  append-only ledger and now includes the later owner corrections.

## Useful experiment, bounded status

`constraint_path_mass` is worth retaining as a probe sidecar. It enumerates a
finite Mini-Lev policy, constructs a probe-relative quotient and leftover
mass, measures topology, applies mutations, compares simple retrieval
proposals, and lets SMT write a bounded disposition. It is not an attractor
basin, a jointly evolving entropy/topology law, or spinor memory.

## Not part of the product

- Grok's separate `/Users/joshuaeisenhart/cb` tree is a shadow prototype, not
  the unified system. Its provider council was disabled, its state was not
  append-only, and its crossing checks were weaker than the current product.
- `run_owner_wave_spine.py` launched external providers and global files rather
  than the contained runner. It is excluded.
- `campaign_path_mass.py` replayed useful rows but bound host-specific source
  paths. It remains experimental until re-derived from contained inputs.
- `mass_tool_probe.py` duplicated the stronger JAX/QIT profile probe and is not
  a second authority surface.
- Authored/spec-only failure, repair, strategy, Goodhart, object-loop, and
  management waves are not counted as live waves.

## Why Grok drifted

Grok was given a broad, moving estate and repeatedly optimized for a small
object it could complete. It built a separate project, counted a deterministic
sequence as a finished product, and treated disabled council cells as a
campaign shape. The repair is structural: one current folder, one public
command, manifest-selected source closure, exact runnable-wave labels, and
fresh-extract tests. More prose cannot substitute for those constraints.
