# CB Premortem Wave

Validate `wave.json`, bind one target digest, and run all declared `cb-premortem-cell` children independently. Each child gets a distinct 2–4 mini-voice combination per round.

After divergence, normalize findings, select only authorized finite repairs, apply them in the designated temporary workspace, then rerun the same lenses. Stop on no material delta, all declared falsifiers settled, cancellation, or the round cap.

Emit one wave receipt that retains every child receipt, repair digest, rerun delta, disagreement, cancellation, and terminal reason. Do not open a web UI or emit standalone premortem documents.
