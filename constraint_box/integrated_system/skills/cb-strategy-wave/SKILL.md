# CB Strategy Wave

This wave evaluates direction, not code correctness. It consumes the current context snapshot plus failure and repair receipts.

1. Bind the target, context snapshot, failure receipt, and repair receipt by digest.
2. Use `mmm-preload` for every model-backed member. Mini voice combinations only; provider/model assignments are invocation data.
3. Run three independent members: systems boundary, object/proxy preservation, and divergent futures.
4. Require each member to name evidence, missing context, local-optimization risk, and one finite next intervention.
5. Exchange anonymized outputs only after all three terminate. Preserve contradictions and minority branches.
6. Compile one of: `CONTINUE_CANDIDATE`, `SPLIT_TARGET`, `REQUEST_CONTEXT`, `REJECT_LOCAL_OPTIMUM`, or `CANCELLED`.
7. Write an append-only context delta. Never rewrite previous owner statements, hypotheses, discarded branches, or receipts.

This wave may veto or split work. It cannot make a failed test pass, select a model as kernel policy, or declare release readiness.
