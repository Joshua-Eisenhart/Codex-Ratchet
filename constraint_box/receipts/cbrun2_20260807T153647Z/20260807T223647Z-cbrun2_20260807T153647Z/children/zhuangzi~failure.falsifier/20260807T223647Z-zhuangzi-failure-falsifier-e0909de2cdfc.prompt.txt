# Premortem

Use this skill to run Gary Klein-style prospective hindsight: imagine the user's plan already failed six months from now, then work backward to identify why. The goal is not polite risk assessment. The goal is a specific, unsentimental failure analysis that produces a more resilient plan.

Every completed premortem produces:

```text
premortem-report-[timestamp].html
premortem-transcript-[timestamp].md
```

Save both files in the current workspace unless the user specifies another location. Open the HTML report after generating it.

## Context Minimum

Before running the premortem, gather only enough context to satisfy these three requirements:

1. What is being premortemed? State it in one sentence.
2. Who is it for or who does it affect? Identify customers, audience, team, or stakeholders.
3. What does success look like? Define the intended outcome so failure can be meaningfully inverted.
