# ConstraintBox status snapshots

`LIVE_CORE_INDEX.json` and `LIVE_CORE_INDEX.md` are generated by
`scripts/write_core_status.py` in a ConstraintBox-only environment.

They record three different facts separately:

1. the exact core registry;
2. whether each package is visible in the current Python environment;
3. whether one bounded, named API exercise ran.

They do not establish proof, CR validity, external Sim Engines integration, or
release admission. Those are separate products and separate ceilings.
