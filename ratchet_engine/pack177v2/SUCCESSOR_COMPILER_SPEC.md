# Source-agnostic successor compiler

The fresh recursive donor and Pack 177 converge on one missing root mechanism.
Pack 177 v2 now executes the first half: it compiles every measured residual
into typed anonymous obligations and a fair queue. The live engine still cannot
instantiate and execute a plural evidence-licensed candidate packet from those
obligations and feed the returned records back through the frontier.

## Input

The compiler receives only a typed operational residual and immutable context:

\[
\Delta=(X,Y,D,H,\Pi,B),
\]

where \(D\subseteq X\times Y\) is observed support, \(H\) is retained
history, \(\Pi\) declares executable probes, and \(B\) is the finite bound.
Source-family names and owner hypotheses are not compiler inputs.

## Always-licensed candidates

- the exact finite observed relation;
- coarser and finer operational quotients generated by measured coordinates;
- partial functions on contexts with one observed continuation; and
- total deterministic functions only when every observed full context is
  single-valued.

## Evidence-licensed candidates

- a finite transducer only when ordered history is measured;
- a new coordinate refinement only when a source engine can execute the new
  probe and return its value;
- weights only when a declared repeat/measure semantics exists;
- complex amplitudes only when phase-sensitive interference data exist;
- bracket-sensitive or nonassociative carriers only when bracketed histories
  are operationally distinguished;
- spinor carriers only when chirality/lift/holonomy observables are present;
  and
- nested complete-section candidates only when multilayer compatibility and
  reciprocal extension data are present.

Candidate families whose evidence license is absent remain eligible proposals
for a future context, but they are not instantiated with invented parameters.

## Output

The required live output is a packet, not a winner:

\[
P_{r+1}=\{(S_j,U_j,L_j,\operatorname{prov}_j)\}_{j=1}^{N},
\]

with an executable evaluator, declared license, and provenance for every
candidate. The root Ratchet then computes plural MSS frontiers under its
frozen orders and controls.

The authored nested calibration in the donor pack is a tested candidate
grammar for the last lane. It is not a default successor.

`receipts/fuel_obligations.json` is the executed input boundary for this second
half. It must not be replaced by another hand-written planning document.
