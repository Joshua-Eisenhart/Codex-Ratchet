# Level Map And Authority

Date: 2026-05-23

Status: audience map and naming discipline. Not canon by itself.

## 1. The Core Problem

The word `axiom` has been doing too much work.

It has been used for:

1. the owner's deep thesis language;
2. the two executable root constraints;
3. derived anti-smuggling constraints;
4. operational process rules;
5. sim gates;
6. evidence receipts;
7. aspirational proof targets.

Those are not the same thing.

This pack uses a stricter ladder:

```text
owner_thesis
  -> root_constraint
  -> derived_constraint or candidate_fence
  -> operational_extension
  -> sim_gate
  -> receipt
  -> admitted_status, candidate_status, or graveyard_status
```

## 2. The Six Main Levels

```text
This is enforceable because the owner believes it.
```

### L1: Root Constraint

Role:

The minimal operational root kernel currently enforced by the formal ratchet.

Current roots:

```text
F01 = finitude
N01 = noncommutation
```

```text
No completed infinities at root. Every carrier, registry, path family, probe
family, receipt, and claim scope must be finite.
```

```text

```

```text

```

## 3. Why Bounded Work Is Not Bureaucracy

Bounded work is F01 applied to reasoning.

If work is unbounded, then it smuggles:

```text
infinite context
infinite proof search
infinite hidden assumptions
infinite time
infinite authority
```

Those violate the root discipline.

So every serious task needs:

```text
finite scope
finite files
finite carrier or schema
finite command
finite output
finite claim ceiling
finite next step
```

That is not process decoration. It is the model running on itself.

## 4. The Ratchet Shape

The system does not move by "having an idea and accepting it."

It moves by:

```text
translate -> bound -> instrument -> control -> run -> receive -> audit -> admit/kill/refine
```

The graveyard is part of the ratchet. A killed claim narrows the manifold and
teaches the next construction where not to smuggle.
