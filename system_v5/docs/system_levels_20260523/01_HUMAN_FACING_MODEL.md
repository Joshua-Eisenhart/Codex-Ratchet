# Human-Facing Model

Date: 2026-05-23

Status: explanation for humans. Not a proof, not canon.

## 1. The One-Sentence Version

The project asks whether reality, mind, computation, and physics can be rebuilt
from finite distinguishability constraints where order matters, then tested by
turning every good idea into a bounded QIT-aligned sim or proof gate.

## 2. The Owner Thesis In Plain Language

The oldest layer of the model is not "quantum mechanics" and not "FEP."

It is closer to:

```text
Start with no fixed objects.
Start with maximum uncertainty.
Only the distinctions that survive constraints become real for a probe.
```

From that view:

```text
matter      = stable constraint on distinguishability
energy      = changing constraint
geometry    = compatibility structure among constraints
dynamics    = constraint-respecting transformation
information = bookkeeping of distinguishability
entropy     = quantitative readout of uncertainty/distinguishability
identity    = probe-relative indistinguishability, not primitive sameness
```

## 3. Why The Formal Roots Are Only Two

The owner thesis is richer than two lines, but the formal machine currently
uses two operational roots:

```text
F01 = finitude
N01 = noncommutation
```

That is deliberate.

The roots are thin because they are meant to be enforceable. They are not
supposed to contain the whole philosophy. They are the smallest current kernel
that prevents the worst classical smuggling:

```text
F01 blocks hidden infinity.
N01 blocks swap-by-default classical orderlessness.
```

Everything else must be earned.

## 4. Why "Axiom" Is A Risky Word Here

You can still use "axiom" in normal human conversation, but inside the system it
must be split.

Human phrase:

```text
My axiom is that identity is not primitive.
```

System translation:

```text
owner_thesis: nominalist identity
derived_constraint: no primitive identity
operational_gate: indistinguishability under a finite probe family
```

The point is not to police language. The point is to stop LLMs and sims from
treating a sentence as if it were already executable.

## 5. The Holodeck Idea

The Holodeck is the practical engineering version of your FEP intuition.

Human version:

```text
The mind/world-model projects possible worlds, receives error, updates the
model, and uses compressed memory cues to simulate action before acting.
```

QIT-aligned version:

```text
finite world-memory density state
finite projection/action instruments
finite sensor/error effects
finite posterior update
finite memory cue readouts
```

This avoids treating FEP as a classical Markov blanket with primitive
probability and time. The Holodeck becomes a finite QIT-FEP process.

## 6. Axis0 In Human Terms

Axis0 should not be treated as "one magic scalar."

The better current human-facing read is:

```text
Axis0 is the polarity/readout of whether a finite cut-history is becoming more
binding, coherent, predictive, or admissible under the current probe family.
```

It can have several candidate readouts:

```text
log path evidence
coherent information
mutual information
relative entropy
feedback polarity
cut-history order gap
memory/world reconstruction fit
```

The work is to find which candidate survives controls, not to rename one
existing quantity as Axis0.

## 7. Flux In Human Terms

Flux is not a root and not currently canon.

The useful reading is:

```text
flux is a derived current or binding direction on the constraint manifold and
engine runtime.
```

It may connect:

```text
chirality
Hopf/Weyl geometry
engine basin selection
Holodeck policy steering
cut-state information flow
```

Current sims support "flux as a live derived candidate." They do not prove
final flux.

## 8. Why The Graveyard Matters

Failed sims are not wasted.

They show what does not survive the root constraints and controls. That is how
the attractor basin narrows.

The project should treat failures as:

```text
map updates
primitive-smuggling detectors
control-family lessons
proof-target refinements
```

## 9. The Main Goal

The goal is not to make a grand explanation first.

The goal is:

```text
make the deepest ideas operational enough that they can fail.
```

If a piece cannot fail, it is still philosophy or owner thesis. That can be
valuable, but it is not yet ratchet evidence.
