## Non-Negotiable Boundary

### Formal lane

Location:

```text

```

Formal may use:

- read-only source docs;
- repo contracts;
- mathematical target specs;
- clean formal code that is rebuilt in the formal lane;
- local validators and result receipts generated by the formal lane.

Formal may not use as evidence:

- `system_v5/grok_sim` result JSONs;
- Grok/Claude/Gemini conclusion text;
- cross-lane synthesis docs;

- `system_v5/ops/formal_scouts/`;

### External model lanes

Grok, Opus, Gemini, Claude Bridge, and similar routes are advisory unless an
explicit formal ingest/reproduction scout is written.

Their outputs should be stored as advisory receipts or prompts, not as formal
scientific evidence.

## Redo-Specific Negative Controls

Every rebuilt scout should include at least one negative from each bucket where
applicable:

1. **Finitude/capacity:** path-count or boundary-dimension overflow.
2. **Noncommutation:** commuting Pauli/diagonal control.
3. **Gauge/basis:** local unitary on non-observed cut, relabel, or phase flip.
4. **Entanglement:** product-state ablation.
5. **Matched nuisance:** matched-lambda / matched-spectrum / matched-purity
   control.
6. **History:** shuffled-Kraus, reversed order, history-erased/dephased.
7. **Topology/geometry:** fiber/base-only, chirality-only, flux-erased.

No result should be called strong if it lacks a matched nuisance control.

  tested.

  but not evidence.
