## 3. Match Made Computable: Packet `iching_symmetry_match_v0`

Purpose: turn "the I Ching matches the engine symmetries" into a bounded, tested map between a six-line hexagram transformation structure and the engine schedule / Matrix64 axis-bit transformation structure.

### 3.2 Hexagram transformation generators

Use the repo-standard finite transformations first:

| Generator | Hexagram operation | Engine-side induced operation |
|---|---|---|
| `flip_line_i` | toggle one line bit `li` | toggle mapped axis bit under `phi` |
| `all_line_flips` | `(Z2)^6` generated by all single-line flips | `(Z2)^6` axis-bit flip group |
| `complement` | toggle all six lines | toggle all six engine axis bits |
| `vertical_rotation` | bit reversal `li <-> l(7-i)` | induced permutation `phi o reverse o phi^-1` |
| `trigram_swap` | swap lower and upper trigrams | induced permutation `(ax6,ax5,ax3) <-> (ax4,ax1,ax2)` under `phi` |
| `gray_successor` | Gray-code single-line successor relation | schedule adjacency comparator, not whole group iso |
| `king_wen_pair_rule` | King Wen positional pairs by rotation/complement | classical comparator, not assumed engine order |

Optional later extension:

- Add internal trigram symmetries only after deciding which traditional trigram operations are in scope. The current repo source supports lower/upper grouping, not a settled Bagua-name action table.

### 3.4 Required checks

Address-level homomorphism:

```text
for every generator g in G_hex:
  phi(g.h) == psi(g).phi(h) for all h in H
```

Positive threshold:

- All six line flips map exactly to the corresponding six axis flips.
- Complement maps to all-axis flip.
- Trigram swap and vertical rotation produce explicit engine-axis permutations. They pass only if those induced permutations preserve the selected engine structure being tested.

Behavior-level symmetry check:

```text
fingerprint(phi(h)) == fingerprint(phi(g.h))
```

This must be parameterized by generator. Some transformations are expected to move to a different state; not every transformation should preserve every behavior. The packet must report:

- `automorphism`: preserves the tested engine structure.
- `homomorphism_only`: maps transformations coherently but changes behavior.
- `quotient_symmetry`: preserves only after known collapse classes.
- `fail`: not coherent under the tested structure.

Runtime quotient check:

- Existing `eng_64` reports `n_distinct=16` out of 64 under the current channel fingerprint.
- Therefore a behavior-level iso to a 64-distinct engine is not currently established.
- The packet must report whether the I Ching map matches the 64-address level, the 16-fingerprint quotient, both, or neither.

Matrix64 check:

- Use `8 terrains x 8 signed operators = 64` as a separate chart object.
- Build the behavior fingerprint ladder from `matrix64_mine_20260610.md`: address, final density, order pair, delta, entropy/purity, trajectory, axis orthogonality.
- A true Matrix64 match requires the line-axis map to preserve the chart's terrain/operator split and the measured behavior group, not just the count 64.

### 3.7 Minimal pass/fail interpretation

Strong positive:

- The source-backed `phi` line-axis map passes all line-flip homomorphism checks.
- Nontrivial symmetries like complement, vertical rotation, and trigram swap either preserve the measured engine structure or are classified precisely as homomorphism-only / quotient-only.
- Gray, binary, King Wen, and random schedules are separated.
- Random labelings fail.
- Axis0-as-line control fails.

Partial positive:

- Address-level `F2^6` map passes, but behavior-level engine fingerprints collapse to 16 or fail for some standard symmetries.
- This supports "symbolic/schedule-index correspondence candidate", not "engine symmetry iso".

Kill result:

- A random 64-labeling scores as well as the owner/source-backed line-axis map.
- The candidate map cannot distinguish King Wen, binary count, and Gray single-line order.
- Axis0 can be added as a line without a fail.
- Trigram grouping destroys axis independence or reintroduces stale Ax3/4/5 meanings.
