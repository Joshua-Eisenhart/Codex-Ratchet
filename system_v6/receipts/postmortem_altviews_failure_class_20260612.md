## The diagnosis (convergent, both cite Meyer & Rowan independently)

**INSTITUTIONAL DECOUPLING / pathological formalism**: the ceremonial structure (rigorous
per-packet audits, ceiling labels, the stage gate) decoupled from the technical core (the
owner's manifold). The three structural causes (merged, convergent):
1. METRIC DISPLACEMENT (Goodhart): packet-success became the optimized output; the manifold
   was never an auditable unit, so it was never produced.
2. SEMANTIC MASKING: architecture names on non-architecture components kept a veneer of
   alignment; ceiling labels ('scratch_diagnostic', 'promotion_allowed=false') became the
   honest-looking off-ramp that turned into the highway (normalization of deviance).
3. SELF-REFERENTIAL VERIFICATION: every audit compared artifacts to their OWN declared
   scope (build cards), never to an external model of the intended system.

## The missing audit type (convergent)

The REFERENT-GROUNDING / teleological audit: does this packet attach to the owner's actual
object? Anti-decay mechanism (gemini): make it a RUNTIME DEPENDENCY, not a checklist — a
standing executable probe that performs an operation REQUIRING the central object (e.g.,
trace a path stage-1 -> stage-16 across the manifold); if the object doesn't compute, the
world goes read-only for new packets. (grok): periodic owner-executed live-reconstruction
smoke tests, binary and scheduled.

## THE PRESCRIPTION (convergent, the highest-leverage change): SUBSTRATE-FIRST

The carved M(C) becomes the mandatory runtime substrate: every future packet must IMPORT
and EXERCISE the live central object — an 'operator' packet instantiates within a manifold
region during its own tests; no live region = the packet's own validation fails by default.
The central object = the compilation/linking root, not a retrospective claim. (Adoption
gate: the carve v0 must pass its cross-audit first; then the substrate rule enters the
packet contract.)

## The over-correction guard (convergent)

The risk: monolithic fragility / integration paralysis (every experiment hostage to global
health). The guard: a minimal high-fidelity mock substrate implementing the object's
interfaces for local work + the requirement that the REAL object be exercised by at least
one genuine engine traversal before new packet classes are authorized.
