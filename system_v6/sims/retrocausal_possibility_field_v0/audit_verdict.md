## The caveat (the precise next target, not hidden)

total pairwise compatibility mass, independent of which shell a branch sits on or the shell radius
ordering. So "INWARD multi-shell compression" is, dynamically, shape-labeled but not shell-structured:
the shells are a labeling of the data, not load-bearing in `compression_map`. Equivalently, the
orientation INWARD/OUTWARD is an asserted string label, not an emergent flow (builder concurred).
