## Caveats

- **G1 - Object-scope caveat.** This closes the S8 program's three-spinor floor table, not the `stage_lifted_spinor_shell_n8_v0` eight-site shell object. The committed n=8 shell packet pins `N_QUBITS=8` and `shell_nested_hopf_torus_support`; this packet pins `(C^2)^x3` dimension 8. Those are different objects.

- **G2 - Cross-engine independence caveat.** The full 66-row table is generated by the Python common module and imported by the JAX and PyTorch receipts. Julia/QuantumOptics independently recomputes the q0|q1q2 scalar subset for GHZ, Bell, W, nested r2/r3, and the Phi0 fixture. So the cross-engine result is real for the shared scalar vector, not a full independent three-backend recomputation of all 66 table rows.

- **G3 - Dual-stack anchor caveat.** The Phi0 anchor is recomputed from a locally constructed two-Schmidt-coefficient fixture chosen so that its `I_c` equals `0.4164955306996874`. It is a numerical continuity anchor, not a rebuild of the full dual-stack S-to-M channel object.

- **G4 - Channel-control caveat.** The identity-channel object is constructed before table evaluation. The erased-channel control is an analytic erasure formula row, not a CPTP erasure map applied to the table state objects.

- **G5 - Type-system caveat.** Type-confusion rejection is shown by a deliberate `TypeConfusion` exception path. That is a structural failure control, not a general typed-entropy parser or schema typechecker.

- **G6 - Tool-honesty caveat.** `QuantumOptics`, z3/cvc5, SymPy, qutip, and `torch.func` are exercised and gated, but qutip and `torch.func` are not independent full-table engines. Cite them as tool receipts/checks, not as proof that qutip/PyTorch computed every S8-local row.
