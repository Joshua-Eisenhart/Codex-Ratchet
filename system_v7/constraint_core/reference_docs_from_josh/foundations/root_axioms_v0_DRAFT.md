## Formal Homes And Deltas

ALIGNED-FORMAL-HOME: Bishop-style setoids are a clean formal home for "sets carry their own equality." Fit: equality is not global primitive equality but an explicit equivalence relation packaged with the carrier. Delta: the owner's `~_M` is finite, physical, probe-relative, and can tighten under added constraints; a setoid equality is usually a given static relation inside a formal system.

ALIGNED-FORMAL-HOME: HoTT univalence, `(A = B) ≃ (A ≃ B)`, is a clean formal home for identity-as-equivalence. Fit: identity is not mere syntactic sameness; equivalence carries identity content. Delta: the owner's equivalence is operational and constrained by finite probes, not a universe-level type-theoretic identity principle; the ratchet refines which equivalences survive.

ALIGNED-FORMAL-HOME: Operational quantum theory is the physics-side home. Preparations are equivalent when no allowed measurement distinguishes them, and density operators summarize preparation equivalence classes at a probe resolution. Delta: standard operational QM usually takes the allowed experiment class and Hilbert framework as given; the owner's system asks which finite probe families, carriers, and quotient structures survive constraints in the first place.

ASSISTANT-GLOSS: These homes are allies, not authorities. They show the root claim has rigorous neighbors, but none of them should be imported as the foundation unless their primitive identity/equality assumptions are fenced off from the claim path.

## Quarantine List

ALIGNED-FORMAL-HOME: FOL identity and reflexivity axioms quarantine: standard first-order logic often makes `x = x` load-bearing. Policy: use FOL only when the proof path does not depend on primitive self-identity as ontology, or when identity is explicitly treated as an internal formal convenience fenced away from `~_M` claims.

ALIGNED-FORMAL-HOME: ZFC extensionality quarantine: standard set theory identifies sets by having the same members. Policy: use ZFC/set notation as bookkeeping only when the member/equality assumptions do not decide the root claim; retool root claims as finite carriers plus explicit equivalence/probe/admissibility relations.

ALIGNED-FORMAL-HOME: Category-theory strict identity quarantine: objects and morphisms usually carry strict identity morphisms and equality in the metatheory. Policy: up-to-isomorphism reasoning, equivalence of categories, and "avoid evil" instincts are allies; strict object/morphism identity is quarantined when it would smuggle `a=a` into the foundation.

ASSISTANT-GLOSS: Quarantine does not mean toss. A quarantined tool may be used when its primitive-identity presumption is fenced off from the claim path and the live claim is carried by finite probes, admissibility, quotienting, order tests, or explicit bracketing controls.
