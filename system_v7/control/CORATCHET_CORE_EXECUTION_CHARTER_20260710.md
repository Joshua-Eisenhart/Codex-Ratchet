canon.

The replacement makes four corrections that this charter did not state
precisely enough:

   equivalence relation is not present until earned.
2. Geometry and entropy are typed co-views computed from one admitted
   distinction boundary. Neither is prior to the other, and their shared
   source does not imply that they are numerically identical tensors.
3. MSS uses a declared and defeasible weakness preorder. It preserves plural
   incomparable minima and can demote an earlier admission when a weaker
   carrier later satisfies the same frozen obligations.
4. The recursive core is not currently earned. In particular, four substages,
   sixteen distinct intelligences, Type-1/Type-2 engine closure, learned
   perception, and Axis0 alignment remain blocked consumers.
