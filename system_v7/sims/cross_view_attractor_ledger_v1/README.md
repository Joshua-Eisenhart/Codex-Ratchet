# cross_view_attractor_ledger_v1

Classification: `proposal_only`. This replaces the decorative evidence logic of
`one_object_many_projection_registry_v0`; it does not replace that artifact's
provenance record.

The ledger operationalizes a strong-nominalist target: a shared attractor is
not a hidden object behind domain views. It is the invariant overlap that
survives independently built projections, dynamics, translations, and paired
ablations.

## Evidence Ladder

```text
analogy
< structural_match
< shared_invariant
< semiconjugate_dynamics
< cross_domain_prediction
```

`validate_ledger.py` is deliberately only an admission-ceiling gate. It checks
that no row claims a level whose required executable receipts are absent. A
green validator means the proposal is honestly typed, not that the domains are
unified.

## Required Upgrade For A Row

To reach `semiconjugate_dynamics`, a row needs independent core and domain
dynamics plus a measured residual for

```text
Q_d(T(x)) ~= T_d(Q_d(x)).
```

To reach `cross_domain_prediction`, it additionally needs a frozen prediction
transported into another domain and a paired intervention that breaks the
claimed shared structure in both views.

The first recommended executable cards are Carlen-Maas terrain geometry and a
finite tilted-history/quantum-Doob gate. Neither is presently implemented by
this ledger.
