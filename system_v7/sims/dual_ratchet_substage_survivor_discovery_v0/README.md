# Dual-Ratchet Substage Survivor Discovery v0

This packet tests one prerequisite below the conditional `16 x 4` execution
instrument. The owner rule is exact: every source stage uses all four base
operators as its four substages at one shared Axis-6 operator/terrain
precedence; the native operator fixes phase or emphasis, not exclusion. This
packet does not execute that stage interior. It asks only whether an anonymous
channel family yields a four-class operator basis without beginning with
`Ti`, `Te`, `Fi`, and `Fe` as the four answers.

The candidate objects are anonymous sampled channel families. The main finite
universe contains all three Pauli axes, several strengths, both directions of
each rotation path, identity duplicates, isotropic depolarizing channels,
amplitude-damping channels, and a non-CP transpose control. Geometry and
entropy receive the same anonymous maps but use disjoint measurements:

- geometry sees affine Bloch action, fixed-direction dimension, unitality,
  Choi positivity, and terrain/operator commutator norms;
- entropy sees only density spectra, von Neumann entropy, and Umegaki-relative
  entropy responses to the eight terrain fixed points.

Neither selector receives operator names, source licensing, x/z labels, or a
desired survivor count. Geometry and entropy are fixed extensional filters in
this v0 packet. Their reversed application orders therefore test receipt and
set-intersection plumbing only; they do not constitute a history-dependent or
noncommuting dual ratchet.

The terrain ensemble's signed-permutation automorphisms are discovered from
the eight exact affine flow maps. This is important: the current house terrain
set has an exact proper-rotation symmetry that places x and y in one orbit and
z in another. The packet asks whether both independent scalar/vector
measurement lanes recover that quotient rather than assuming it.

## Required Controls

- candidate enumeration permutations;
- three independent symmetry-closed probe seeds;
- fingerprint-threshold sweep;
- identity, depolarizing, damping, and non-CP controls;
- terrain-isotropy erasure;
- rotation-side erasure;
- source-only x/z restriction;
- two generic non-Pauli axis families.

The generic-axis challenge is a kill gate. If the Pauli registry yields four
classes but generic axes add survivors, the result is conditional on the
finite Pauli-axis registry and cannot be called foundational emergence.

## Ceiling

This is a `scratch_diagnostic`. A positive main result can at most earn four
terrain-relative operator quotient classes inside a declared finite Pauli
registry. It cannot establish four substages inside each source stage, choose
their order, derive native phase, choose the x representative of the
transverse x/y class, establish Type-1/Type-2 engine semantics, satisfy the
full history-dependent R1-R6 ratchet definition, or admit QIT engines, Axis0,
perception, or objects.
