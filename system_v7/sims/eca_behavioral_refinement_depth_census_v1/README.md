Preregistered N9 extension of the exact finite behavioral-object depth census.

## Frozen Question

For every unordered distinct pair of elementary cellular-automaton rules on the
full periodic nine-bit carrier, how many strict partition refinements are
required before the fixed Hamming-weight/domain-wall probe becomes stable under
both actions?

The pair universe, depth convention, downstream symmetry-orbit audit batches,
V2 admission thresholds, controls, and claim ceiling were committed before
`run_jax.py` or `run_julia.jl` existed.

## Primary Object

The primary object is the complete 32,640-record N9 ledger. A list of deepest
pairs, a depth histogram, a learned proxy, or one runtime's labels cannot
replace it.

Strict depth counts only partition-changing rounds. The first unchanged update
is recorded separately as `first_equality_round = strict_depth + 1`.

## Downstream Benchmark Gate

Before N9 labels existed, all simultaneous pair-symmetry orbits were assigned
to two hidden audit batches by the frozen SHA-256 order. The split contains
8,808 pair orbits, exactly 4,404 in each batch.

This split does not make the exact census a learning benchmark. It asks only
whether enough symmetry-distinct depth-greater-than-six fixtures and enough
state-pair target changes exist to justify writing a separate V2 card.

If the admission thresholds fail, the required result is
`INSUFFICIENT_DEPTH_NOVEL_MASS_FOR_LEARNED_V2`. Thresholds may not be lowered
after seeing N9.

## Ceiling

Even a complete green result supports only an exact finite N9 ECA depth census
under the frozen probe and boundary. It cannot establish learned perception,
runtime intelligence, QIT stages, four substages, the 16-by-4-by-2 schedule,
MMMs, ontology admission, a universal attractor, Axis0, physics, life, or
consciousness.
