# ECA Observation Object Identifiability V0

Preregistered exact scout for the information boundary that must precede any
new learned-perception benchmark.

## Question

Given only a bounded packet of raw action-labelled trajectories, is a queried
stable behavioral-object relation:

- impossible to determine because compatible hidden dynamics disagree;
- determined only because the observations uniquely identify the hidden rules;
- or fixed across several genuinely different compatible dynamics?

The third case is the only perception-like candidate. This packet measures it;
it does not train a learner.

## Frozen Universe

- periodic nine-bit ECA carrier;
- 531 label-independent test rule-pair symmetry representatives;
- all 9,636 unordered distinct state pairs sharing the initial probe;
- 16 deterministic length-four action-word trajectories;
- cumulative observation budgets `1,2,4,8,16`;
- all 65,280 ordered distinct rule-pair hypotheses.

The split, manifests, packets, budgets, queries, version-space definitions, and
regime gates were committed before either exact builder existed.

## Exact Semantics

For visible observations `D`, the version space is every ordered rule pair that
matches all observed transitions while preserving persistent action-token
meaning.

For each query, every compatible hypothesis independently induces an exact
stable partition under the fixed Hamming-weight/domain-wall probe.

The query is:

```text
must_equal     all hypotheses say same object
must_separate  all hypotheses say different objects
ambiguous      compatible hypotheses disagree
```

Ambiguous queries are not converted into negative labels.

## Regime Boundary

Singleton version spaces are system identification, not perception.

Consensus is claim-bearing only when at least eight effective unordered
hypotheses and at least two distinct full partition relations remain. A
perception-like window requires two consecutive frozen budgets, broad
identifiability, at least 100 qualifying symmetry families, at least 50,000
consensus queries, and a balanced must-equal/must-separate target.

All budgets remain visible. This scout cannot retrospectively select one N9
budget as a sealed learning benchmark. A future learner requires a new card and
untouched families.

## Engine Contract

- Julia independently builds the exact semantic/version-space ledger.
- JAX independently builds the batched exhaustive ledger.
- The controller compares every claim-bearing field and attacks the receipts.
- PyTorch is excluded until the exact scout shows that a learnable question is
  information-theoretically meaningful.

## Ceiling

A green exact scout can classify the finite ECA observation regime only. It
cannot establish learnability, general perception, semantic authority, QIT
stages, four substages, the 16-by-4-by-2 schedule, MMMs, ontologies, Axis0,
physics, life, or consciousness.
