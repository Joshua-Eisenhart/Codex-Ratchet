# ECA Relation-Directed Observation Design V1

This packet asks whether the negative V0 result was caused by its inherited
hash-order observation schedule.

It is an exact target-aware experimental-design scout, not a learner. Search
engines may use stable relation truth on 128 frozen design fixtures, screen all
2,500 size-two through size-four subsets, and exact-score a frozen shortlist.
They may not read validation, test, parent engine, or peer results.

All three size winners must be frozen in a committed receipt before separate
confirmation sources exist. Validation cannot rank or replace them. The old V0
test block is historically consumed and can only be conditional secondary
confirmation.

The primary gate is intentionally severe: every validation fixture must retain
several compatible dynamics and several full stable relations, no fixture may
be system-identified, and both full-query and query-disjoint relation coverage
must pass.

Even a green result would establish only a finite target-aware measurement
design under one ECA carrier and probe. PyTorch, learned perception, spontaneous
object formation, QIT stages, four substages, MMMs, ontologies, and Axis0 remain
blocked.

## Closed Result

The train search froze winners at sizes two, three, and four before confirmation
sources existed. Independent JAX and Julia confirmation then compared equal on
all 2,925 shared validation fixture/design records. Zero sizes passed the
preregistered gate, so the packet closes `PREREGISTERED_CONFIRMATION_RED` and
the reused test block remains unopened.

This negative result is useful: a single fixed global observation subset cannot
simultaneously preserve model diversity and deliver broad relation coverage in
this finite carrier. See `RESULTS.md`, `GATE_STATUS.md`, and
`FABRICATION_AUDIT.md` for the exact boundary.
