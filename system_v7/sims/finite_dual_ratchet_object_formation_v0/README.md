# Finite Dual-Ratchet Object Formation v0

This lane asks a smaller question than the QIT schedule:

```text
Can four distinct executable roles form and preserve one finite behavioral
object across perspectives, and does removing each role break a frozen gate?
```

The four roles are `measure`, `distinguish`, `quotient`, and `gate`. They are a
candidate object-factory cycle. They are not identified with `Ti/Te/Fi/Fe`, and
they do not derive four QIT substages.

The carrier is a deterministic two-action automaton on sixteen base states,
lifted to sixty-four states by four behaviorally equivalent copies. The exact
object is the coarsest probe-respecting congruence under the two actions. Four
state relabelings and one action-swapped relabeling provide different views of
the same object.

The preregistered census over seeds `1..20000` is intentionally broader than
the depth-four target set. It is a kill test for universal four-count wording:
depth four is rare, and the battery may use it as a difficult fixture without
calling it forced.
