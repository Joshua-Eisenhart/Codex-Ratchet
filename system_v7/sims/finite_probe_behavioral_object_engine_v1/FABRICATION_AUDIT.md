## Findings

1. The model starts from exact probe equality and receives the two exact
   paired-successor edges at every ordered state-pair node. Six shared message
   passes mirror the declared behavioral-refinement recurrence.
2. Every frozen fixture stabilizes after only one strict refinement. The
   depth-one exact baseline is already perfect. The benchmark therefore does
   not test deep learned refinement.
3. The three-checkpoint ensemble scores `1.0` MCC, but individual-seed MCC is
   `[0.0, 0.0, 0.9366614989322403]` under the frozen global threshold.
4. Shuffled-label training still scores `0.9627052748084781` MCC, far above the
   preregistered maximum `0.05`. The architecture-generated ranking survives
   destruction of the learning labels.
5. The optimizer-erased model scores `0.8311452924819083` MCC. This is not a
   null learned system.
6. The two structural partition hashes are genuinely absent from train and
   validation, but they are still one-refinement fixtures. This is a narrow
   structural holdout, not general object formation.
7. Primary test partition structures already occur in train and validation.
   The split tests unseen rule-symmetry families, not arbitrary unseen
   behavioral structures.

graph can produce a perfect ensemble readout on symmetry-family-disjoint ECA
rules and two held-out partition hashes. Training may calibrate that installed
operation. The result does not establish independent discovery, robust
seedwise learning, learned perception, general object formation, or runtime
non-substitutability.
