# Capstone draft unaudited — ratchet_coratchet_loop_v0

Status: DRAFT_UNAUDITED.

Promotion allowed: false.

This module tests whether an append-only quotient lift can license later readouts
that then force a subsequent lift under a persistent witness gate.  A distinction
counts only after it persists for K consecutive ticks in the fact stream
(default K=3; NumPy sweeps K=2..5).

The headline observable is the long-run lock curve: total persistent locks,
total co-turns, and the last tick that minted a new lock.  A single co-turn event
is not sufficient, because the old discriminator also let kill controls show a
co-turn.  The honest v0 success condition is entangled-memory strict dominance
over every kill control in both total locks and co-turns, while feedback-cut
still kills all co-turns.

No dominance result is required for success; a null headline is an honest
outcome and would be evidence against this drive doctrine.
