# Tolerance-to-Equivalence Ratchet Rung v1

This replaces the v0 tooth claim with a preregistered semantic-forcing lane.
The v0 packet remains immutable evidence of a mechanically green but designed
pair-collapse-loss fixture. Finishing its Lev replay would not make it a forced
Ratchet tooth.

The v1 reference oracle is generic over finite instances. It enumerates every
equivalence between the raw tolerance T and current equivalence E0, recomputes
loss and drive, returns the full Pareto front, and commits only when that front
contains exactly one admissible relation. A plural front and every nonpositive
drive HOLD.

This directory currently contains only the frozen math, fact generator,
reference oracle, mutation contract, preregistration validator, and tests. The
three engine builders are deliberately absent. No tooth, promotion, or launch
is authorized.
