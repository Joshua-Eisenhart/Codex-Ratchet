# Unseen Finite Predictive Objects v0

This packet tests a narrow learned-perception claim on a prospective finite
registry. An object is the exact finite-horizon predictive equivalence class
of a four-state binary unifilar process. The learner sees only independent
masked and corrupted output trajectories. It never receives state numbers,
machine definitions, object hashes, view seeds, split labels, or a generating
bijection.

The manifest, splits, short-horizon-matched test pairs, architecture, seeds,
thresholds, and controls are frozen before learner source or any test score
exists. The Python generator owns only that frozen registry proposal. Julia
must independently reconstruct and verify every exact semantic field; any
disagreement blocks the packet rather than changing the sealed registry.

The pair construction matches exact length-one and length-two behavior and
uses longer-horizon divergence only as a tie-break. It is therefore a
short-horizon-matched challenge set, not a claim that the pairs are maximally
hard for length-128 observations.

Passing would establish only bounded learned recovery and prediction on this
one finite process family. It would not establish exact machine recovery,
general perception, QIT engines, four substages, MMMs, FEP, or physics.
