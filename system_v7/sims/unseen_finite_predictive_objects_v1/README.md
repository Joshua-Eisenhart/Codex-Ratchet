# Unseen Finite Predictive Objects v1

UFPO v1 is the repaired successor to the scientifically invalid v0 learner
pilot. It tests a narrow supervised multi-view claim on wholly new finite
processes and views.

The exact object is still the length-one-through-eight predictive equivalence
class of a minimal strongly connected four-state binary rational unifilar
process. Python proposes the frozen registry. Julia must independently verify
its semantics. The Python/JAX lane supplies exact batched numerators, frozen
views, leakage checks, and solver controls. PyTorch may learn only from lossy
visible trajectories and training relations.

Primary grouping uses leave-one-view-out nearest-view retrieval. It receives
no object count. Prediction must beat train-mean, order-two, histogram, and
temporal-shuffle controls for every seed. `torch.func` is supportive only.

The registry files alone do not authorize a test run. A seal is valid only
after every engine, learner, baseline, metric-recomputation, and controller
source is tracked and hash-bound. A test result path is single-use and may not
be overwritten.

A green result would establish only bounded supervised multi-view predictive
retrieval on this synthetic family. It would not establish unsupervised object
discovery, general perception, QIT engines, the four-substage schedule, MMMs,
ontologies, Axis0, FEP, physics, life, or consciousness.
