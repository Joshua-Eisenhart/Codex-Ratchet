# Strawman-detector audit — system_v8 candidate set

**Auditor role:** adversarial strawman detector, read-only. Hunting the owner's exact
failure: does this set fake cross-family diversity so the ratchet can be driven cheaply
without earning each level?

**Judged against:** `ROOT/ROOT_CARD.md` (owner verbatim, outranks all) and
`system_v7/constraint_core/RATCHET_SPEC.md` v0.5.

**Status of this file:** `exists` — an audit opinion, not an executed result. It edits
no candidate, commits nothing.

---

## Bottom line

The set is **legitimate cross-family fuel, not a strawman factory.** Four different
authors, three genuinely distinct carrier families, a real presumption spread, and each
member carries probes and a can-fail witness rather than bare prose. No member is filler.
The deliberately weak member (classical, sonnet) is a real defensible floor, not a
knock-over.

But it is **not yet an adequate minimum range for a load-bearing pairwise MSS comparison.**
The carriers diverge; the **judging apparatus does not**. All four take the demand/probe
family as an exogenous given and rest the MSS verdict on one weakness relation (partition
refinement). There is executed evidence that the only demand set run so far was too thin
to tell nine carriers apart — so a pairwise tooth run against it now would be a fixture
artifact, which is precisely the owner's stall-or-fake mode arriving through the shared
judge instead of shared candidates.

**Verdict:** clears the strawman bar; needs three specific additions before any pairwise
MSS result would mean anything (named in the last section).

## Shared blind spot across all four (the most dangerous finding)

The carriers diverge; the **judge is monocultural.** Two shared, uncriticised commitments
sit upstream of every candidate:

**(A) The demand/probe family (D, M) is taken as an exogenous given.** Every candidate
evaluates against a supplied set of demanded distinctions and a supplied probe family. None
makes D or M a first-class rival that is itself varied and compared, and none makes
D-robustness a condition of its own verdict. Candidates 3 and 4 at least *flag* grammar
thinness (§6d; §6-weakness-1); candidates 1 and 2 take it for granted. This is inherited
from the frame (the packet supplies D) and left uncorrected by the whole set.

**(B) One weakness relation.** All four rank minimality by partition refinement /
coarsening. The spec explicitly flags "rival categorical, computational, resource,
predictive, or dynamical preorders remain live digs" (RATCHET_SPEC §6) — and no candidate
offers one. This is the uniformly uncritical shared commitment.

**Why this is the owner's failure mode, one level up.** A strawman set is normally caught by
shared *carriers*; this set's residual risk is the shared *judging apparatus* (D, M, ≼)
that converts fuel into a verdict. And there is executed evidence the judge is currently too
weak to discriminate: candidate 3 cites `base_campaign`, where the only demand set run so
far (two packets) returned `restricting_outer_changes_inner: false` and
`order_T2T1_equals_T1T2: true` for **all nine** base carriers — under the real D tested,
the coupling/evolution signal could not separate any carrier from any other. Run the
pairwise MSS comparison against a D that thin and it will not separate these four strong
carriers either: the ratchet stalls (`DIG_CONTINUES` forever) or manufactures a tooth from
a fixture artifact. Only candidate 3 surfaces the thinness; the other three inherit it
silently.

Minor shared assumption, frame-sanctioned and lower-risk: all four assume finitude (F01)
without proposing a continuum rival. The frame treats F01 as a standing pressure, so this
is aligned, not a defect — noted for completeness.

Frame-alignment positives (evidence *against* a factory): all four root correctly in
constrained distinguishability; all use the L_D coface reading; none silently installs an
equivalence relation at the root (3 explicitly guards against it); each maps to a different
strand of the owner's verbatim core. A strawman factory would not bother aligning each
rival to the owner's words.

## Decisive set-adequacy verdict

**Legitimate minimum range for FUEL: yes. Adequate for a meaningful pairwise MSS comparison:
not yet.** Hold both — they are both true.

The set clears the strawman bar decisively: four authors, three distinct carrier families,
a real presumption spread from minimal-classical to maximal-top-down, probes and can-fail
witnesses throughout, and a weak member that is genuinely weak-by-design rather than filler.
Nothing here is one LLM's authored answer wearing four masks.

It is not yet adequate to *compare*, for four named reasons:

1. **The shared judge must be broken before any pairwise tooth counts.** Fix and then
   **vary** a demand/probe family D thick enough to discriminate — the executed evidence
   shows the only D tried so far could not separate nine carriers. Add at least one rival
   weakness relation to partition refinement. Without this, a pairwise MSS result is a
   fixture artifact regardless of how good the carriers are. This is the load-bearing gap.

2. **The nonassociative rival is under-built and frame-tensioned.** The nonassociative
   family (which the frame wants) is currently represented only by a candidate that
   *installs* nonassociativity at the floor against the frame's "association-unspecified /
   emerges" rule. Harden it or replace it with one where a nonzero associator **emerges from
   a witnessed grouping distinction**, so it is a strong rival rather than the cheapest
   member to eliminate.

3. **Named families and orders the frame requires are absent.** No live CA/QCA carrier
   (RATCHET_SPEC §5, constraint_core CLAUDE.md #16 name it as a family that must compete —
   candidate 3 only *rejects* the automaton reading, none proposes a live cellular rival).
   No middle-out / "depths both ways" order (owner line 4: "more depths going both ways") —
   all four are cleanly bottom-up or top-down. The presumption mid-range is thin: the repo
   already has queued but un-written rivals (`rebit_carrier`, `complex_density_matrix`,
   `jordan_structure`, `quaternionic_carrier`) that would sit between classical-relation and
   full-complex-density+spinor.

4. **Nothing has burned.** All four are `exists`-tier prose; only candidate 3 is wired to
   executed receipts, and even it leaves Layers 1–2 un-simulated. There is currently nothing
   to actually compare — the fuel is ready but unlit.

**Recommendation:** treat the set as a valid *starting* fuel spread. Do item 1 (the shared
judge) before running any pairwise MSS comparison; do items 2–3 to make the range genuinely
cover the frame's families. Until item 1 is done, any MSS tooth from this set would be the
owner's stall-or-fake outcome wearing a comparison's clothes.
