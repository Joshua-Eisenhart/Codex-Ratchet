# Codex Ratchet v9 controller surface

This directory is the v9 routing surface, not a copy of systems v4-v8. Those
trees remain working reference and evidence estates.

CR v9 owns stage order, candidate routing, and explicit bridge invocation. It
does not own the implementations of ConstraintBox, ClaimGate, Sim Engines, or
Holodeck. The stack verifier checks those product and bridge boundaries before
any integrated campaign is described as v9.
