# V9 bounded source intake

This directory records source-addressed curation decisions for material that
remains outside the repository. It is an index and distillation surface, not
an archive mirror.

Rules:

- record archive hashes before interpreting contents;
- prefer audited derivatives over their original candidate packs;
- copy no receipt/result tree merely because it is large;
- reuse a repository source when its byte hash already matches;
- keep unadopted code as a named candidate, never as active authority;
- carry defects forward as executable-test requirements.

The current Desktop pass is in `DESKTOP_CURATION_20260806.md` and its
machine-readable index.
